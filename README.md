
**FitMotion AI**

A beginner-friendly AI fitness assistant.

## Problem
Gym beginners may struggle to select suitable exercises,
understand exercise technique, and plan workouts.

## Solution
FitMotion AI provides an exercise library, workout planner,
and AI coach powered by a Gemma open-weight model.

## Features
- Exercise library with instructions and demonstrations
- Personalized workout plans
- AI fitness question-and-answer assistant
- Beginner-friendly interface

## Technology
- Python
- Streamlit
- Google Gen AI SDK
- Gemma 4 26B A4B IT

## Setup
1. Install Python.
2. Clone or download this repository.
3. Create and activate a virtual environment.
4. Install dependencies using:
   pip install -r requirements.txt
5. Create a .env file with your API key and model ID.
6. Run:
   streamlit run app.py
